# 🎓 College Event Management App

A modern Flutter-based College Event Management App that helps students discover, register for, and manage college events with secure Firebase Authentication and Cloud Firestore integration.

---

## 📱 Features

### 🔐 Authentication
- Secure Login
- User Registration (Sign Up)
- Firebase Authentication
- Logout functionality
- Password visibility toggle

### 🎉 Event Management
- Browse upcoming college events
- View detailed event information
- Register for events
- Store registrations in Firebase Firestore

### 👤 User Profile
- Modern Profile UI
- Display logged-in user's email
- View registered events
- Logout securely

### 📋 My Registrations
- View all registered events
- Delete registrations if required
- Real-time Firestore data

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Krutikakhamkar-7/college-event-app.git
```

Move into project

```bash
cd college-event-app
```

Install dependencies

```bash
flutter pub get
```

Run the application

```bash
flutter run
```

For Web

```bash
flutter run -d chrome
```

Build Web

```bash
flutter build web
```
